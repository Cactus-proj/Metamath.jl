# Data

This directory contains the databases for the Metamath project.

* "[hol.mm](./hol.mm)" aka "Higher-Order Logic Explorer"
* "[miu.mm](./miu.mm)"  - a simple formal system for use as a
  demonstration based on work by Hofstadter.
